03 · Resources

Tools that approximate the inputs — not the judgment

Star counts and URLs were verified with the GitHub API on 13 November 2026 (Asia/Shanghai). No repository backtests Camillo’s discretionary eye. These are tools for search interest, conversation, sentiment, consensus, and options research. Full table: research/03-resources.md.

Google Trends

One of his favorite early-warning tools. Use a five-year window. In 2025 he warned that AI-generated queries may pollute the series.

RepositoryStarsPurpose
GeneralMills/pytrends3,730Unofficial Python client for interest-over-time. Archived. This toolkit patches a urllib3 v2 incompatibility and still uses it.
akvise/trends-checker404CLI on pytrends with tighter rate-limit and cookie handling.
yiromo/pytrends-modern76Maintained Trends client, a fork-of-forks.
flack0x/trendspyg65Modern, maintained pytrends alternative with a CLI.
mikedbjones/longtrends16Long-term Trends series — the window Camillo prefers.

Academic companions: Preis, Moat & Stanley, Scientific Reports 2013; Da, Engelberg & Gao, “In Search of Attention,” Journal of Finance 2011.

TikTok comment scraping at the scale he describes has no high-quality, stable open-source library we could recommend. Treat TikTok as a manual research surface. Reddit’s public JSON was 403 from this project’s build network; the code path is still in the toolkit for residential or authenticated use.
