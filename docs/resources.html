Google Trends

他早期预警最爱用的工具之一。使用五年窗口。2025 年他警告，人工智能生成的查询可能污染这条序列。

One of his favorite early-warning tools. Use a five-year window. In 2025 he warned that AI-generated queries may pollute the series.

Hashtag view and video counts are now in this repo via the public /api/challenge/detail/ endpoint (and TikTokApi as a cross-check) — see the street-view page. Comment-level scraping at the scale Camillo describes is still a manual research surface; we did not collect comments. Reddit’s public JSON was 403 from this project’s build network; the code path is still in the toolkit for residential or authenticated use.
